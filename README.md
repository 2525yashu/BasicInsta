# Basic Instagram structure
A lightweight, modern replica of Instagram built using React, Socket.IO, and Zustand for state management. It supports interactive real-time features, secure user authorization, and a responsive media feed layout.

🚀 Features
* User authentication with JWT and secure password hashing
* Responsive design built for seamless mobile and desktop browsing
* Frontend: React and Tailwind CSS
* Backend: Node.js and Express.js
* Database: MongoDB + Mongoose
